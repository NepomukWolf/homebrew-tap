# Homebrew Tap for mdglance

This repository contains the Homebrew formula for
[mdglance](https://github.com/NepomukWolf/mdglance), a keyboard-first Markdown and SVG previewer.

## Install

```sh
brew install NepomukWolf/tap/mdglance
```

Then open a document:

```sh
mdglance README.md
```

## Upgrade

```sh
brew update
brew upgrade mdglance
```

## Uninstall

```sh
brew uninstall mdglance
brew untap NepomukWolf/tap
```

## Platform support

The currently published bottle supports Apple Silicon Macs running macOS 15 Sequoia or newer.

For source code, documentation, issues, and release notes, visit the
[mdglance repository](https://github.com/NepomukWolf/mdglance).
